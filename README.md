# PayChain source code
This is the source code for our Thesis in iACADEMY.

PayChain, a salary disbursement platform powered with blockchain technology.

## Hierarchy of the project:
```
paychain
├── backend - Backend for PayChain using Flask and Python
├── contracts - Smart contracts for PayChain using Solidity
├── frontend - Frontend for PayChain using React Native and Expo
```
